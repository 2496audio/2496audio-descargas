2496audio - Descargas Oficiales
Te damos la bienvenida a la página oficial de descargas de 2496audio.
Aquí encontrarás los instaladores de nuestra colección de plugins de audio en formato VST3. Todas nuestras herramientas son 100% gratuitas (freeware), no contienen adware, no requieren registro y no recopilan datos personales. Puedes usarlas en tus proyectos personales y comerciales.
//
🎛️ Catálogo de plugins
Nuestra colección actual incluye:
FG_CutSsssv2 - Spectral De-esser. Diseñado para atenuar las sibilancias ("eses") en voces con precisión quirúrgica, con analizador de espectro, lookahead y auto-detección.
FG_ConsoleStrip - Channel Strip. Emulación de canal de consola analógica para dar color, pegada y carácter a las pistas.
FG_GraphicDual3 - Ecualizador gráfico. EQ de 8 bandas con modo canal y modo bus, respuesta de fase suave y tres tipos de curvas musicales.
FG_VocalAtelier v2 - Procesador vocal. Suite todo en uno: compresor soft-knee, saturación analógica y ambiente (reverb/delay).
FG_XRayAnalyzerv2 - Analizador visual. Herramienta de monitoreo para comparar el espectro de la señal procesada con una referencia.
//
💻 Requisitos
Windows 10 u 11, 64 bits.
Un DAW compatible con plugins VST3.
Por ahora no hay versiones para macOS ni Linux.
📥 ¿Cómo descargar?
Ve a la sección Releases de este repositorio.
Descarga el instalador del plugin que quieras, por ejemplo `FG_CutSsssv2_Setup.exe`, de la versión más reciente.
Ejecuta el instalador y sigue las instrucciones. El plugin se instalará automáticamente en tu carpeta de VST3 (`C:\Program Files\Common Files\VST3`).
Abre tu DAW, escanea los plugins y ¡listo para mezclar!
> **Descarga solo desde esta página.** No nos hacemos responsables por copias obtenidas en otros sitios, que podrían estar modificadas.
⚠️ Aviso de Windows SmartScreen
Los instaladores no están firmados digitalmente, por lo que Windows puede mostrar el mensaje "Windows protegió su PC". Para continuar, haz clic en Más información y luego en Ejecutar de todas formas.
Para comprobar que el archivo no fue alterado, compara su hash SHA-256 con el publicado en las notas de cada versión. En PowerShell:
```powershell
Get-FileHash .\FG_CutSsssv2_Setup.exe -Algorithm SHA256
```
